## Regenerating this archive

```sh
cargo run -p elang-conformance --bin gen_release_archive
```

The generator is idempotent: re-running it on an unchanged tree rewrites nothing.

## Limits of this archive

- The digests prove **what** the bytes are, not **who** produced them.
- The archive covers the *inputs* to the release (dependencies, normative data, conformance fixtures). The release binaries themselves are produced by the `reproducible-build` workflow, which records their reproducibility evidence separately.
- No artifact in this archive is signed, and v0.1.0 makes no publisher-authenticity claim.
